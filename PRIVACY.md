# Privacy Policy

**Last updated:** 2026-10-05

## TL;DR

This repository is **documentation plus one optional local script**. **Nothing about your use of this skill is collected, transmitted, stored, or seen by the maintainers.**

## What this project is

Markdown files (skill content, framework notes, layered guidance, checklists, templates) installable as a Claude Code plugin or referenced from Codex CLI / Cursor / GitHub Copilot via `AGENTS.md`, plus `scripts/ai-governance-check-changed-files.py`, a changed-file checker that runs only when you invoke it and prints to your own terminal.

## What we collect

Nothing:

- **No source code** from your repository is read by the maintainers. The checker reads your local git diff on your machine and sends it nowhere.
- **No findings or review output** are reported back — analysis runs inside your own agent session.
- **No telemetry**, usage data, cookies, tracking, device IDs or IP logging.

## Third parties

The project transmits no data, so shares none. If you host a copy elsewhere, that platform's privacy practices apply.

## Hosting

The project is hosted on GitHub at <https://github.com/AltByteSG/imda-ai-governance-skill>. GitHub collects standard request and account data under [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement); the maintainers don't receive it.

## Children

This project is technical reference material aimed at adult software engineers. It is not directed at children, and because nothing is collected, no data about children could be collected even inadvertently.

## Changes to this policy

Any change to the data-collection posture will be recorded here and in [`CHANGELOG.md`](CHANGELOG.md). The position is: **no data collection, by default or otherwise**.
